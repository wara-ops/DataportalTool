# Naming conventions

The naming convention for dataportal files is maintained in one place only:

`wcib/docs/namingconvention.md` (in the `wcib` repository)

This file used to hold a copy, which drifted out of date. Refer to the
authoritative document for the metric and log layouts, the canonical
`.zst.parquet` spelling for plain parquet with zstd columns, the `.zst` (never
`.zstd`) compression suffix, and the retirement of uncompressed `.pkl` for new
uploads.
